# 📦 Sistema de Control de Stock - Forrajería

Aplicación desarrollada en **Java** utilizando **Programación Orientada a Objetos (POO)**, **Java Swing** para la interfaz gráfica y **MySQL** como base de datos. Permite gestionar el inventario de productos en una forrajería con funcionalidades completas de **CRUD** (Crear, Leer, Actualizar, Eliminar).

---

## ⚙️ Funcionalidad

- **Ingreso de productos**: Captura datos como nombre, cantidad, precio y descripción.
- **Visualización de productos**: Tabla con todos los productos registrados.
- **Edición y eliminación**: Opciones para modificar o eliminar productos existentes.
- **Validaciones y excepciones**: Controla la entrada de datos y maneja errores.
- **Interfaz gráfica interactiva**: Realizada con Java Swing, amigable y funcional.

---

## 🧩 Estructura del proyecto

El proyecto está organizado en paquetes según su responsabilidad:

- **main**: punto de entrada, limpio y organizado.
- **controllers**: controla el flujo de las operaciones CRUD.
- **services**: lógica de negocio para gestionar productos.
- **database**: configuración y conexión con la base de datos MySQL.
- **igu**: interfaz gráfica con ventanas y tablas interactivas.

---

## 🏗️ Arquitectura

- **Código modular y desacoplado**: Facilita mantenimiento y expansión.
- **Interfaz gráfica (Swing)**: Interacción fluida y eficiente para el usuario.
- **Base de datos MySQL**: Almacenamiento de productos con operaciones CRUD.
- **Validaciones y control de excepciones**: Garantiza entradas correctas y manejo de errores.
